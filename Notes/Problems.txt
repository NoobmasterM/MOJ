1. UNDERSTANDING THE PROBLEMSET & DETAIL SYSTEM MARKS
-------------------------------------------------------------------------------
* MathJax Engine Components (<MathJaxContext> & <MathJax>):
  - Problem statements downloaded from a database often contain raw LaTeX math 
    strings (e.g., "$O(N \log N)$" or "$\sum_{i=1}^n$").
  - The context wrapper initializes the browser's typesetting compiling script.
  - The internal <MathJax> components intercept raw strings and render them into 
    pixel-perfect, high-utility mathematical equations on the interface.

* String Escaping Engine (String.raw``):
  - Used directly alongside the backtick interpolation layout inside descriptions.
  - It forces JavaScript to fully ignore backslash processing rules (\n, \t). This 
    ensures raw math commands remain completely pure when passed into compilers.

* Nested Conditional Arrays Layout:
  - Inside ProblemSet tags column mapping, notice the nested inline evaluation:
    'tag === "DP" ? "primary" : tag === "Graph" ? "info" : ...'
  - This is a nested ternary chain. It acts like a switch statement to assign 
    specific, explicit branding colors to topics (Blue for DP, Cyan for Graphs).

2. COMPONENT LIFECYCLE & THE PARSING FLOWCHART
-------------------------------------------------------------------------------
This diagram charts how unstructured database entries are converted into layouts:

          [USER ASSIGNS OR REQUESTS A VIEW]
                          │
                          ▼
            [THE USEEFFECT NETWORK BOOT]
  Fires 'apiClient.getProblem(id)' or 'getProblems()'.
  Retrieves database rows into memory.
                          │
                          ▼
          [THE DATA NORMALIZATION GATEKEEPER]
  The raw row is automatically routed through helper utilities:
  • 'getRatingFill()': Maps numeric scores into visual gauge metrics.
  • 'normalizeTags()': Normalizes data variants (Strings vs Arrays).
                          │
                          ▼
             [THE ERROR-PROOF ARRAY SPLIT]
  If tags were saved as a plain string string ("DP,Math"), 'JSON.parse()' catches 
  the failure, breaks strings apart by commas, and cleans empty array offsets.
                          │
                          ▼
            [COMPILER STRUCTURAL RENDERING]
  • Map loops transform sanitized elements into specific grid columns.
  • MathJax typesets character structures into math notation layouts live!
