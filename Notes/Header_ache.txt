1. DESIGN & NAVIGATION STRUCTURE
-------------------------------------------------------------------------------
* Theme Variant ('data-bs-theme="dark"'):
  - Forces React-Bootstrap to invert text colors to white automatically so text 
    remains completely visible over the custom purple background color.

* The Session Layout Variant (Ternary Conditional Render):
  - '{user ? ( ... ) : ( ... )}' checks if your user state tracking token exists.
  - Profile Flow: If true, it extracts 'user.username' and paints a custom link 
    to '/profile' alongside a clickable 'Logout' text trigger.
  - Gatekeeper Flow: If null, it completely hides profile layouts and displays 
    a clean 'Login' text path directing traffic to '/login'.

2. USER SYNCING ACTION FLOWCHART
-------------------------------------------------------------------------------
This diagram charts exactly how the application validates user authenticity on boot:

      [USER LOADS OR REFRESHES PAGE]
                    │
                    ▼
       [INITIAL ENVIRONMENT CHECK]
  Checks browser 'localStorage' cache memory
  for an existing user footprint data block.
                    │
                    ▼
     [BOOT UP USEEFFECT HOOK STAGE]
  Fires 'apiClient.getCurrentUser()' to ask 
  the backend server if this session token is valid.
                    │
         ┌──────────┴────────────────────────┐
         ▼ (Server Validates Token)          ▼ (Server Denies / Offline)
   [LOCAL CACHE REFRESH]               [BACKUP FALLBACK GATE]
     • Receives fresh profile object.    • Catches validation error.
     • Overwrites localStorage cache.    • Reverts to cache backup data.
     • Sets user object into state.      • If cache empty: sets state to null.
                    │                                │
                    └───────────────┬────────────────┘
                                    ▼
                     [CUSTOM SYSTEM EVENT MONITOR]
     Binds 'window.addEventListener' tracking to target 'mojUserChanged'.
     If any component fires a change event, Header updates instantly!
