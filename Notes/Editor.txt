-------------------------------------------------------------------------------
1. DESIGN & STRUCUTURAL ARCHITECTURE
-------------------------------------------------------------------------------
* The Monaco Editor Engine (<Editor />):
  - Height="400px" locks container proportions.
  - theme="vs-dark" loads an automated high-contrast dark programming canvas.
  - wordWrap: "on" stops code lines from extending horizontally off-screen.
  - minimap: { enabled: false } removes the tiny code bird's-eye map to maximize 
    valuable user coding screen real estate.

* Complex Multi-Condition Alert Layouts (Conditional Short Circuits):
  - {output && ...} renders an independent success block when standard output logs.
  - {error && ...} catches compilation alerts, showing details in red.
  - {submissionResult && ...} builds an algorithmic evaluation summary.
  - Evaluates submissionResult.summary.status === "ACCEPTED" to dynamically paint 
    the result header green (Success) or bright red (Wrong Answer/Runtime Error).

   • If compiling succeeds: updates data  "Failed to submit code".
