===============================================================================
                  MARKUP INTEGRATION: VANILLA HTML VS JSX
===============================================================================

-------------------------------------------------------------------------------
1. THE FUNDAMENTAL DIFFERENCE
-------------------------------------------------------------------------------
* Vanilla HTML: A static document format read directly by the web browser.
* React JSX: A syntax extension for JavaScript that looks like HTML. It gets 
  compiled down into raw JavaScript objects before hitting the web browser.

-------------------------------------------------------------------------------
2. STRUCTURAL SIMILARITIES
-------------------------------------------------------------------------------
* Tag Names: The base structural tree tags (<p>, <div>, <h1>, <table>) are the 
  exact same tags used to create web structures.
* Nesting Rules: Elements nest inside each other using matching opening and 
  closing blocks in an identical parent-child DOM layout pattern.

-------------------------------------------------------------------------------
3. WHAT REACT JSX HAS THAT HTML DOES NOT
-------------------------------------------------------------------------------
* Dynamic Evaluation Execution (The Curly Braces {}):
  - HTML: Hardcoded static values only -> <p>User: Alice</p>
  - JSX: Can evaluate active code variables -> <p>User: {user.username}</p>

* Embedded Logic and Array Looping:
  - JSX allows embedding complex logical transforms like '.map()' or ternary 
    operators directly inside layout sections to print structural fragments.

* Custom Structural Components:
  - You can create your own modular tags. Using '<Editor />' or '<Header />' 
    injects entire nested sub-systems inside your base screen layouts.

-------------------------------------------------------------------------------
4. WHAT HTML HAS THAT REACT JSX FORBIDS (THE COMPILER RULES)
-------------------------------------------------------------------------------
* Single Parent Rule:
  - HTML: Allows multiple root sibling tags globally in a document file.
  - JSX: Every layout block must return exactly ONE single wrapper parent tag, 
    otherwise, compilation fails. (Use React fragments '<> ... </>' to group siblings).

* Mandatory Tag Closures:
  - HTML: Forgives missing closures on specific self-closing tags -> <input type="text">
  - JSX: Throw an absolute critical compile error if any tag lacks a trailing backslash -> <input type="text" />

* Attribute Name Replacements:
  - Since JSX is compiling into JavaScript code, reserved language tokens 
    cannot be used as HTML property attributes:
    1. Replace HTML 'class="..."' with JSX 'className="..."'
    2. Replace HTML 'for="..."' with JSX 'htmlFor="..."'

* Inline Style Objects:
  - HTML: Uses a standard flat text configuration string -> style="color: red;"
  - JSX: Requires an explicit structured property object container -> style={{ color: 'red' }}
===============================================================================
